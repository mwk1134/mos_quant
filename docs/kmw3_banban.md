# KMW3 반반매매 (ATR70-R2)

KMW3는 2026년 10월 20일에 투자원금 **$80,000**으로 시작하는 반반매매
프리셋이다. 처음에는 ATR70에 $40,000, 정배열 R2에 $40,000을 배분하고,
추가 시드증액 없이 각 전략의 현금과 보유분을 따로 계산한다.

반반매매는 기존 ATR70-R2 전략의 화면 이름이다. 전략 식별자와 매매 규칙은
유지한다. ATR은 Wilder 방식의 70일 ATR을 사용하고, R2는 완료된 QQQ 주봉
RSI와 SOXL 정배열 조건에 따라 진입 규칙을 선택한다. 월중 비중은 변동하며,
매월 첫 미국 거래일에 두 전략의 자산을 50:50 목표로 재배분한다.

KMW3의 보유분·현금·성과는 시작일부터 완료된 일봉을 순서대로 재생한
**시뮬레이션**이다. ATR 돌파 체결과 익일 시가 청산, R2 종가 주문 및 월초
리밸런싱에는 연구 엔진의 가격·비용 가정을 적용한다. 표시된 보유수량과
주문안은 실제 증권계좌의 잔고나 접수 내역을 뜻하지 않는다.

KMW3를 선택해도 기존 계좌의 실제 체결 장부와 자동매매 활성화 상태는
바뀌지 않는다. KMW3는 실계좌 자동주문 지원 목록에 추가하지 않는다.

계산은 `banban_strategy.py`와 고정 원본 커밋에서 가져온 연구 엔진을 사용한다.
원본·변경 사항은 연구 패키지에 함께 기록한다. 최신 시장 데이터를 확인하지
못하면 완료된 기준일을 확인하고 화면의 데이터 상태를 따른다.

최초 저장된 모의 결과의 기준일은 **2026-10-28**이다. 최신 확정 시세를
확인하면 다시 계산하며, 조회에 실패하면 저장된 자산·과거 성과만 표시하고
오늘의 주문안은 표시하지 않는다. 비용 가정은 매수·매도 각각 0.05%이고,
슬리피지는 0%다.

# KMW3 반반매매 (ATR70-R2)

KMW3는 2026년 10월 20일에 투자원금 **$80,000**으로 시작하는 반반매매
프리셋이다. 처음에는 ATR70에 $40,000, 정배열 R2에 $40,000을 배분하고,
추가 시드증액 없이 각 전략의 현금과 보유분을 따로 계산한다.

반반매매는 기존 ATR70-R2 전략의 화면 이름이다. 전략 식별자와 매매 규칙은
유지한다. ATR은 Wilder 방식의 70일 ATR을 사용하고, R2는 완료된 QQQ 주봉
RSI와 SOXL 정배열 조건에 따라 진입 규칙을 선택한다. 월중 비중은 변동하며,
매월 첫 미국 거래일에 두 전략의 자산을 50:50 목표로 재배분한다.

KMW3의 보유분·현금·성과는 시작일부터 완료된 일봉을 순서대로 재생한
**시뮬레이션**이다. ATR 돌파 체결과 익일 시가 청산, R2 종가 주문 및 월초
리밸런싱에는 연구 엔진의 가격·비용 가정을 적용한다. 표시된 보유수량과
주문안은 실제 증권계좌의 잔고나 접수 내역을 뜻하지 않는다.

KMW3를 선택해도 기존 계좌의 실제 체결 장부와 자동매매 활성화 상태는
바뀌지 않는다. KMW3는 실계좌 자동주문 지원 목록에 추가하지 않는다.

계산은 `banban_strategy.py`와 고정 원본 커밋에서 가져온 연구 엔진을 사용한다.
원본·변경 사항은 연구 패키지에 함께 기록한다. 최신 시장 데이터를 확인하지
못하면 완료된 기준일을 확인하고 화면의 데이터 상태를 따른다.

번들에 저장된 모의 결과의 기준일은 **2026-11-02**이다. 전체 기간을 날짜로
지정해 일봉을 조회하며, 최신 확정 시세를 확인하면 다시 계산한다. 조회에
실패해도 매수·매도 추천 목록은 유지한다. 저장된 계산의 기준일이 최신 확정일과
같으면 해당 추천을 사용하고, 과거 기준이면 가격·수량을 확인 대기로 표시한다.
비용 가정은 매수·매도 각각 0.05%이고,
슬리피지는 0%다.

화면이 열려 있으면 1분마다 최신 확정 거래일을 확인한다. 미국 거래소의 실제
장 마감 시각을 기준으로 다음 거래일 추천을 계산하므로 주말·휴장일·서머타임과
조기 폐장도 같은 기준으로 처리한다. 시세 갱신 버튼은 관련 일봉 캐시와 실패
재시도 대기를 함께 해제한다. 시세 조회가 복구되면 추천도 자동으로 다시 계산한다.

매일 ATR70과 R2의 매수·매도 조건을 각각 표시한다. 진입 조건 미충족이나 회차
소진 시에는 신규 매수 없음으로 표시하고, 보유분의 목표가·만기 매도는 유지한다.
월초 비중 조정 전에는 조정 후 달라질 수량을 확정하지 않고 재계산 대기로 표시한다.

추천 지정가는 0.01달러 단위로 반올림하며, 해당 가격의 추정 수수료까지 포함해
전략별 예산을 넘지 않는 수량으로 제한한다. 과거 성과의 전략 기준가격과 추천
주문가격을 별도로 보존한다. 추천을 확인하는 동작은 모의 장부의 정산·시드를
진행시키지 않는다.

`오늘의 매매`는 기존 프리셋과 같은 `🟢 매수 추천`·`🔴 매도 추천` 목록을
가장 먼저 표시한다. 각 항목에 ATR70/R2, 회차, 주문 유형, 가격과 수량을
표시하며, 매도 항목에는 매수일·매수가·진입 모드·만기일을 함께 표시한다.
가격·수량이 확정된 매수 추천을 대기 항목보다 먼저 보여준다. 자산·모의
보유분과 프리셋별 MDD는 접어 두며, 필요할 때 펼쳐 확인한다.
